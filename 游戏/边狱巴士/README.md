# 边狱巴士

英文名 *Limbus Company*。v51 的译文按 Steam 构建 26652290 的韩文校对。

## 用安装器安装

退出游戏，在科特星恒汉化在线安装器中点「检查更新」，选「边狱巴士」，确认游戏目录后安装。如需手动选择目录，在 Steam 库右键游戏，选择「管理 → 浏览本地文件」，选中含有 `LimbusCompany.exe` 的这一层。

## 手动安装

1. 从本仓库对应发行版的附件下载 `limbus-zh.zip`，退出游戏。
2. 把包内的 `LimbusCompany_Data` 文件夹合并到游戏根目录。
3. 首次安装时保留包内的 `LimbusCompany_Data/Lang/config.json`，它会启用「简体中文-星恒科特汉化」。如果已启用这套汉化并自定义过配置，可在手动复制时保留自己的配置文件。使用安装器时，同名配置如有差异会先备份再替换。
