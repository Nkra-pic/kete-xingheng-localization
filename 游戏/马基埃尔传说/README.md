# 马基埃尔传说

英文名 *Tales of Maj’Eyal*，简称 ToME4。本汉化包适用于 Windows Steam 版 1.7.6。

1. 在本仓库的 Releases 中找到「马基埃尔传说」的最新发行版，下载附件 `tome4-zh.zip`，解压到临时文件夹。
2. 退出游戏。在 Steam 库中右键点击游戏，选择「管理 → 浏览本地文件」。在能看到 `t-engine.exe` 的这一层，依次打开 `game`、`addons` 文件夹。
3. 将压缩包内 `game\addons` 中的两个 `.teaa` 文件原样复制到游戏的 `game\addons` 中。如果已有同名插件，可先复制一份旧版留存。
4. 启动游戏，在语言设置中选择「科特星恒汉化」。
