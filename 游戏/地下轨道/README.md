# 地下轨道

英文名 *Underrail*，适用于 Windows 版。

1. 在本仓库的 Releases 中找到「地下轨道」的最新发行版，下载附件 `underrail-zh.zip`，解压到临时文件夹。
2. 退出游戏，打开同时含有 `underrail.exe` 和 `data` 文件夹的游戏根目录。Steam 玩家可从游戏的「管理 → 浏览本地文件」找到它。
3. 汉化包包含修改过的游戏主程序和数据文件。手动安装前先备份游戏目录，再将压缩包内的文件和子文件夹按原有结构复制到游戏根目录，合并文件夹并替换同名文件。
4. 启动游戏，在主菜单打开 **Options → Language**，选择「科特星恒汉化」。如果游戏提示重新启动，按提示重启。
